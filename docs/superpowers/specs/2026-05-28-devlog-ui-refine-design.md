# LiLink devlog UI 精修设计稿

- **日期**:2026-05-28
- **状态**:方向已与用户确认,待 review
- **范围**:devlog 站点 UI 排版精修(以首页「翻书」布局为主,文章页排版一并对齐)

## 1. 背景与目标

devlog 首页目前是一套「翻书」布局(已在工作区完成、尚未提交):左侧 sticky 目录,右侧用纯 CSS `:target` 一次显示一条更新、点目录切换。

本次在**保留这套骨架与现有"暖色书卷"调性**的前提下,把**布局 / 排版 / 视觉 / 导航**四方面精修到精致阅读型文档站(Stripe、Linear、Astro 文档)的排版水准。

> 不改布局范式、不改品牌调性;只做"细节到位"的打磨。

## 2. 设计前提(事实)

- 7 篇文章**均无封面图**,作者**均为"LiLink 团队"** → 精致感靠纯文字排版撑起;每条重复的署名应弱化。
- 内容**只有时间维度**(无标签/分类) → 导航围绕时间(ISO 周分组)。
- 现有设计系统:`tokens.css`(暖米黄 + 酒红、衬线 display + 无衬线 body、圆角/阴影/容器宽度)、`prose.css`(长文排版,首页与文章页共享)。

## 3. 设计原则

- 深化现有 DNA,不另起炉灶。
- 排版纪律优先:克制字阶、统一间距律动、收窄中文行宽。
- 纯文字也能精致:靠层级、留白、对比撑质感,不依赖图片。
- 中文优先的排版细节:去伪斜体、断行、标点。
- 渐进增强:核心交互(条目切换、上一条/下一条)纯 CSS + 锚点即可用;JS 只做增强(键盘翻页、目录滚动跟随)。

## 4. 详细设计

### 4.1 布局与信息架构
- **正文行宽收窄**:阅读区测量宽度 44rem → 约 36rem(中文 ~32–36 字/行)。落为变量 `--measure`。
- **目录区呼吸感**:15rem → 约 16.5rem;目录项标题限 2 行(`-webkit-line-clamp: 2`)、加大行距,不再挤成一团。
- **页头门面**:强化目录头 `toc-head` 作为站点门面——品牌标题 + 一句 lede + 小统计("共 N 篇 · 跨 M 周"),统计在 `index.astro` 由 posts / weeks 计算。
- **弱化署名**:首页阅读区把"LiLink 团队"并入日期元信息行、降级为次要;独立文章页保留正常署名。

### 4.2 文字排版与可读性(`prose.css` + 页面 header)
- **拉开字阶**(模块化比例):正文 1.0625rem;`.prose h3` ≈1.25rem、`.prose h2` ≈1.5rem;文章大标题 `clamp(1.75rem, 3.5vw, 2.25rem)`。层级一眼分明。
- **修中文"伪斜体"**(明确硬伤):`.eyebrow`、首页 `.page-summary` 与文章页 `.summary` 去掉 `font-style: italic`;改用字重 / 字号 / 颜色 / 字距区分。`<em>` 等西文斜体保留。
- **统一垂直律动**:段落、标题上下、列表、区块间距统一到 `--space-*` 刻度(见 4.3)。
- **中文断行**:标题 `text-wrap: balance`,正文 `text-wrap: pretty`,消除孤字与尾字单行。

### 4.3 视觉精致度(`tokens.css`)
- **间距 token 化**:新增 `--space-*` 刻度(0.25rem 步进基准),替换散落的 magic number。
- **行宽变量**:新增 `--measure`(≈36rem)。
- **去虚线**:`.page-foot` 的 `dashed` 边偏廉价,换成极细实线(`--color-border`)或纯留白。
- **用色克制**:酒红仅用于链接 / active / featured★;打磨 `toc-item` hover、active 指示条、分隔线。
- **数字对齐**:日期、统计统一 `tabular-nums`。

### 4.4 浏览与导航(`index.astro` + inline script)
- **上一条 / 下一条翻页** ⭐:每个 `.page` 底部加"← 更新的一条 / 更早的一条 →"锚点链接(指向相邻 post 的 `#id`),纯 CSS 可用;首条隐藏"更新的"、末条隐藏"更早的"。
- **目录 active 自动滚入可见**:在现有 `syncActive()` 里对 active item 调 `scrollIntoView({ block: "nearest" })`。
- **键盘翻页**:inline script 监听 `←` / `→` 在相邻 post 间切换 `location.hash`(输入框/可编辑元素聚焦时忽略)。
- **时间感**:阅读区 header 标注"第 M 周 · 日期";`page-foot` 的"单独页面 ↗"改为明确的"永久链接 / 分享"语义(仍指向 `/posts/{id}`)。
- **窄屏(≤820px)**:目录改为可折叠的紧凑导航(默认折叠、展开选条),阅读区 + prev/next 成为主浏览方式;保留"一次一条"语义。

## 5. 涉及文件
- `src/styles/tokens.css` — 新增 `--space-*`、`--measure`。
- `src/styles/prose.css` — 字阶、间距律动、中文断行、去伪斜体。
- `src/pages/index.astro` — 页头统计、署名弱化、正文行宽、prev/next、时间感、窄屏目录折叠;inline script(滚动跟随 + 键盘)。
- `src/layouts/PostLayout.astro` — 文章页 header 与 `prose` 对齐(去伪斜体、字阶),署名保留。
- `src/lib/posts.ts` / `dates.ts` — 如需"相邻条 / 统计 / 周数"辅助,优先复用现有 `groupByWeek`、`isoWeekParts`。

## 6. 验收标准
- `npm run build` 与 `npm run check` 通过,无类型 / 构建错误。
- 桌面与窄屏(≤820px)下:翻书切换、prev/next、键盘 `←/→`、目录高亮跟随均正常工作。
- 中文无伪斜体;正文行宽收窄;字阶层级分明;间距统一。
- 由用户在 `localhost`(HMR)肉眼确认观感;具体数值(行宽、字阶、间距)以实现初值为起点,据实际渲染微调。

## 7. 非目标(YAGNI)
- 不引入单列流、不改「翻书」范式。
- 不改品牌色板与字体族。
- 不新增标签 / 搜索 / 分页 / 暗色模式 / 封面图体系。
- 不改写内容(MDX 文案)。
